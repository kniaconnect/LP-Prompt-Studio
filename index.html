Prompt Studio

New project

    1. Product brief

    Tell the studio what you are promoting. Optional fields can stay empty; the generated prompt will tell Claude not to invent them.

    Tip: put one benefit per line to see each one in the preview.

    2. Design discovery

    How do you want to set the visual direction?

    Select one primary style. You can change it any time.

    Your own style

    A reference is visual guidance only. It is not permission to copy another brand's logo, text, photos or code.

    The image stays in your browser. It is not uploaded anywhere. When you use the prompt in Claude, attach the screenshot to that chat yourself.

    The studio cannot read your reference. The mockup uses this preset, and your reference notes go into the prompt.

    Four questions, then a fixed set of rules scores the eight presets. This is simple matching, not AI analysis.

    3. Content and offer

    Leave unknown values empty. Nothing is invented for you: empty prices, proof and claims stay empty in the preview and in the prompt.

    If empty, the preview shows a draft headline built from your description and benefit.

    Brand colors

    Type color names (for example "biru muda, orange, putih") or hex codes, and/or pick colors below. The preview and the prompt use your colors instead of the style's default colors.

    Add testimonials with names and photos in the Images block above. If you add no proof at all, the prompt tells Claude to skip testimonials and numbers.

    Copywriting formula

    Pick up to three, or leave on Automatic. Claude blends them instead of printing the labels on the page.

    Images

    Use direct links to images that are already online (for example uploaded to Lynk.id, Canva, Imgur or your own site). The prompt carries the links, not the files. Links must be public and start with https://.

    Testimonials

    Real customer words only. Add a photo link or a screenshot of the original message if you have one.

    More images

    Product mockups, bonus images, real before/after results, your photo, or real certificates. Each image says where it belongs.

    Real numbers

    For counters and progress bars. Only true, current figures (for example "Modules: 11" or "Seats filled: 40%"). Nothing is invented, and you must update them yourself later.

    Page features and effects

    Choose what the page should do. Each feature shows whether it works on the platform you picked. Lynk.id only allows inline CSS, so some effects are simplified or left out.

    4. Page planner

    Switch sections on or off and change their order. Not every page needs every section.
